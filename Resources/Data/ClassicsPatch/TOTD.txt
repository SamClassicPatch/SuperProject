You can quickly setup Classics Patch to the desired configuration by running new scripts under the following menu:\n^cffffffOPTIONS -> EXECUTE ADDON
You can run Squirrel scripts from the console in the custom mod by prefixing the input with ^cffffffsq>^r or by using regular console commands:\n- ^cffffffscr_ExecuteString^r for executing a script from a string\n- ^cffffffscr_ExecuteFile^r for executing a script from a game file\n- ^cffffffscr_ResumeVM^r for continuing execution of a suspended VM
You can launch Classics Patch with any other mod by selecting it from the "MODS" menu after starting Classics Patch.
You can customize blood color in the custom mod by configuring it under the following menu:\n^cffffffOPTIONS -> CLASSICS PATCH -> Common patch settings
You can enter photo mode in any mod by recording a demo of the game or joining a multiplayer game as an observer and toggling the ^cffffffocam_bActive^r command.
If you mount both The First Encounter and Revolution games in The Second Encounter, the levels from The First Encounter will be replaced by the ones from Revolution.\nKeep that in mind when managing saves and demos from those levels.
If you are still experiencing the slowdown bug in your singleplayer games, run the following commands:\n^cffffffpck_GameplayExtNumber("Enable", 1.0);^r\n^cffffffpck_GameplayExtNumber("FixTimers", 1.0);^r\nWARNING: This will make any subsequent saves and demos in that playthrough incompatible with games without Classics Patch!
You can modify the properties of the Classics Patch config by visiting this menu:\n^cffffffOPTIONS -> CLASSICS PATCH -> Config properties^r\n\nOr by modifying this INI file inside the game folder:\n^cffffffData/ClassicsPatch/Config.ini
You can create your own custom themes for the game menu in the custom mod and for the HUD colors in the Advanced HUD plugin.\n\nVisit the FAQ in the documentation for more info.
You can create your own level categories for the main game or for specific mods by creating new files under this directory:\n^cffffffData/ClassicsPatch/LevelCategories^r\n\nVisit the FAQ in the documentation for more info.
You can use the Server Utilities plugin to replace any items and weapons on vanilla levels without needing to create separate world files and sharing them with others.\n\nFor example: Little Trouble with only double-barrelled shotguns.
When playing levels from Serious Sam Revolution through the custom mod, it will reintroduce enemies and powerups from that game. Otherwise it converts them to compatible alternatives from The Second Encounter.
You can change the FOV in any mod and gamemode by using the new ^cffffffsam_fCustomFOV^r command instead of ^cffffffplr_fFOV^r.
Classics Patch comes with its own "Classics Patch preset" network connection setting that you can manually customize in this menu:\n^cffffffOPTIONS -> CLASSICS PATCH -> Common patch settings
Classics Patch extends gamepad support and allows for proper navigation of the game menu and NETRICSA using them.
When playing in 2-player split screen with the custom mod, you can place player views side by side instead of on top of each other by toggling the ^cffffffgam_bVerticalSplitScreen^r command or by toggling the "Vertical split-screen split" option under this menu:\n^cffffffOPTIONS -> CLASSICS PATCH -> Custom mod settings
You can play user-made levels intended for The First Encounter through The Second Encounter by running the following command before starting the level:\n^cffffffsam_strWorldConverters = "tfe";^r\n\nReset the converters back to an empty string or restart the game before playing regular levels again!
If some level cannot be loaded due to some missing resources, you can substitute them with placeholder resources by entering the following command before loading the level:\n^cffffffsam_bUsePlaceholderResources = 1;
When launching your own servers with Classics Patch, you can use the ^cffffffser_iMaxPlayersPerClient^r command to control the maximum amount of players that can join in split screen mode per client.\n\nFor example: ^cffffffser_iMaxPlayersPerClient = 1;^r prevents clients from joining in split screen mode altogether.
Local Cheats plugin introduces new cheat commands that can be used only by the server client in multiplayer games regardless of the mod or the gamemode. Useful for debugging purposes or when you're stuck somewhere while playing alone.
In the console of the custom mod, you can use the Ctrl+Tab key combination to find commands that contain part of the entered string anywhere in their name, not just at the beginning, as when pressing the Tab key.\nFor example: Typing in "refresh" and pressing Ctrl+Tab will display ^cffffffRefreshTextures()^r, ^cffffffgap_iRefreshRate^r and ^cffffffcht_bRefresh^r commands instead of just the first one.
You can toggle the message font in NETRICSA from the small console font to a higher resolution one by using the ^cffffffcmp_bBigFont^r command. This functionality works across every single mod but it's more thoroughly supported via custom mod that also makes the big font scale with higher screen resolution.
