Generative AI, including large language models (LLMs), should not be used in any way when contributing to Serious Sam Classics Patch.

We want our code to be art. We want to interact with real humans. Please don't submit AI-generated comments or code in bug reports or pull requests. We understand some people consider AI to be a useful tool, but we want to connect with you, not your computer.

Any pull request to this project requires you to confirm that you are the author and that you are contributing your changes under the GNU GPL v2 license.

If any contribution is made using AI, it will be closed without further discussion.
